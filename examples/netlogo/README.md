# Random walks

An original NetLogo Web example for CoMSES Lab. Open `model.nlogox`, click **setup**, then **go**. Explore the population, turn angle, step length, and trail controls. Code, widgets, shapes, and explanatory text are covered by the adjacent MIT license.

The model uses NetLogo 7's XML format and runs with the platform's pinned NetLogo Web 2.15.3 runtime. It has no external files or extensions.
